# QR Melano

موقع مجاني لعمل QR Codes بـ 18 نوع. مفيش قاعدة بيانات ولا تسجيل دخول ولا سيرفر: كل حاجة بتحصل في متصفح المستخدم، والكود بيتحمّل على طول PNG أو SVG أو JPG.

Developed by **Mahmoud Saeid**

---

## الرفع على Vercel (أو تحديث الموقع الموجود)

1. افتح الـ repo بتاعك على GitHub (`qrmelano`) و**امسح كل الملفات القديمة** (فولدرات `netlify` و`supabase` و`public` و`package.json`… كله).
2. ارفع محتوى الفولدر ده كما هو، بحيث يبقى في أول الـ repo:
   ```
   public/
   vercel.json
   netlify.toml
   README.md
   .gitignore
   ```
3. Vercel هيعمل Deploy لوحده خلال دقيقة. مفيش أي Environment Variables مطلوبة. ولو كنت حاطط متغيرات قديمة (SUPABASE…) تقدر تمسحها.
4. افتح الموقع واعمل **Ctrl + F5** علشان المتصفح يجيب النسخة الجديدة.

> لو Vercel سألك عن إعدادات: Framework = **Other**، ومفيش Build Command، والـ Output Directory = `public`. الملف `vercel.json` بيظبط ده تلقائي.

## أنواع الأكواد

| النوع | بيشتغل إزاي |
|---|---|
| Website, PDF, Video, Images, MP3, Facebook, Instagram, WhatsApp | الكود بيفتح الرابط على طول. الـ PDF والصور والصوت محتاجين **رابط**: ارفع الملف على Google Drive أو موقعكم وحط الرابط. |
| vCard, WiFi, Email | البيانات متخزّنة جوه الكود نفسه، وبيشتغل من غير إنترنت. |
| List of Links, Business, Social Media, Menu, Apps, Coupon, Event | الكود بيفتح صفحة موبايل شيك على موقعك (`/v.html`). المحتوى نفسه متخزّن **جوه الرابط** (مضغوط)، فمش محتاج قاعدة بيانات. |

### حاجات مهمة
- **الكود مينفعش يتعدّل بعد الطباعة**، لأن مفيش قاعدة بيانات. لو المحتوى بيتغيّر كتير (أسعار أو عروض)، خلّي الـ QR يفتح صفحة على موقع الشركة وعدّل الصفحة دي.
- كل ما المحتوى يكتر الكود بيبقى أكثف. الموقع بينبّهك لما الكود يبقى كثيف. اطبعه **3 × 3 سم على الأقل**، و**جرّبه بالموبايل قبل الطباعة دايماً**.
- للمطبعة استخدم **SVG**، بيفضل حاد في أي مقاس وبيفتح في Illustrator.
- اللوجو بيتقرا من جهاز المستخدم ومش بيترفع على أي مكان.
- **صفحات اللاندنج تابعة لدومين الموقع.** لو غيّرت الدومين بعد ما تطبع، الأكواد اللي بتفتح صفحة (Menu وBusiness وغيرهم) هتقف. علشان كده ثبّت الدومين النهائي (مثلاً `qrmelano.vercel.app` أو دومين الشركة) **قبل** ما تطبع.

## الأمان
- موقع Static بالكامل: مفيش سيرفر ولا قاعدة بيانات ولا مفاتيح سرية، يعني مفيش حاجة تتسرق.
- Content-Security-Policy صارم (`script-src 'self'`): مفيش سكربتات خارجية خالص، والمكتبات محفوظة جوه الموقع في فولدر `public/vendor`. ومعاه HSTS وX-Frame-Options وnosniff وReferrer-Policy.
- صفحة اللاندنج بتعرض كل النصوص كنص عادي (مفيش HTML)، وبتقبل روابط http/https بس، فمحدش يقدر يحط كود خبيث جوه رابط.
- نوع Apps بيحوّل تلقائي لـ App Store أو Google Play **بس**، فمحدش يقدر يستخدم موقعك للتحويل لمواقع تانية.
- كل الـ 18 نوع اتجرّبوا بقارئ QR حقيقي، واتأكدنا إن كل كود بيتقري بالمحتوى الصح، والعربي كمان.
