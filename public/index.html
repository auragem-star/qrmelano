Questions

Is it free?

Yes, completely. No account, no limits.

Can I change a code after printing it?

No — the content is stored inside the code itself. Tip: for things that change often (prices, offers), point the QR to a page on your own website and update that page instead.

Which file should I send to the printer?

SVG. It stays sharp at any size and opens in Adobe Illustrator. Use PNG for social media and screens.

How small can I print it?

Keep it at least 2 × 2 cm, and 3 × 3 cm or more for codes with a lot of content or a logo. Always test with a phone before printing.
